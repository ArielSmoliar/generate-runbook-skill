# Generate Runbook Support

For installation help, bug reports, safety concerns, or feature requests:

- Review the [README](../README.md).
- Open a [GitHub issue](https://github.com/ArielSmoliar/generate-runbook-skill/issues).

Do not include secrets, credentials, private infrastructure details, saved
content, or sensitive operational evidence in an issue. Use a minimal synthetic
example whenever possible.

Generate Runbook is an open-source project maintained on a best-effort basis.
