# Generate Runbook Terms

Effective date: July 29, 2026

Generate Runbook is open-source software distributed under the
[Apache License 2.0](../LICENSE).

The plugin assists with drafting, reviewing, validating, dry-running, executing,
and auditing operational procedures. Its output is not a substitute for the
user's engineering judgment, security review, legal obligations, change-control
process, or authorization requirements.

Users are responsible for verifying commands, targets, environments,
prerequisites, approvals, rollback procedures, and success criteria before
changing any system. Users must have authorization for every system and action
within a runbook.
