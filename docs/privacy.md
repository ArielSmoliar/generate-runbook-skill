# Generate Runbook Privacy Notice

Effective date: July 29, 2026

Generate Runbook is a skills-only plugin. It does not operate a hosted service,
maintain user accounts, use analytics, or transmit information to the publisher.
The plugin contains instructions, templates, references, and local validation
scripts that run within the user's Codex or Claude Code environment.

The plugin does not require credentials. Users should not place secrets, tokens,
private content, reviewer credentials, or unnecessary personal information in a
runbook. The plugin explicitly instructs agents to keep operational evidence
sanitized and proportionate.

Codex, Claude Code, operating systems, repositories, connected tools, and model
providers may process data according to their own terms, privacy notices, and
workspace settings. Those products and services are outside this plugin's
control.

Questions or privacy concerns can be filed privately or publicly through the
support options listed in [Support](support.md).
